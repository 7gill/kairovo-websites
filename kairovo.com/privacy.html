Privacy policy.

Last updated: April 2026

Short version: Kairovo desktop apps store all data locally on your machine. The studio website collects minimal data for standard operation. We don't sell anything to anyone.

Desktop applications

ScoreSifter, Recital Atlas, AriaDesk and Vocemetry are local-first desktop applications. All data you enter — students, repertoire, lesson records, file paths — is stored in a SQLite database on your own machine. The apps do not transmit this data to any server.

ScoreSifter optionally queries the MusicBrainz API to look up works not found in the local catalogue. This query contains only the filename you're looking up — no personal information, no usage telemetry.

  • No account required to use any app
  • No usage analytics or telemetry
  • No cloud sync or remote storage
  • No data transmitted without explicit user action

This website (kairovo.com)

Kairovo.com is a static site hosted on Cloudflare Pages. Cloudflare collects basic access logs (IP address, page visited, timestamp) as part of normal CDN operation. These logs are held by Cloudflare under their own privacy policy.

We do not run any analytics scripts, ad tracking, or session recording on this site.

Newsletter

If you subscribe to the Kairovo newsletter, your email address is stored with Buttondown (our newsletter provider). We use it only to send Kairovo updates. We do not share it with third parties. You can unsubscribe at any time using the link in any email.

Buttondown operates under their own privacy policy.

Purchases

Paid Kairovo apps are sold through Lemon Squeezy. Payment processing and transaction data is handled entirely by Lemon Squeezy under their own privacy policy. We receive a record of the sale and a license key — we do not see or store your payment card details.

Children

Kairovo apps and this website are not directed at children under 13. We do not knowingly collect information from children.
